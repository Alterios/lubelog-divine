# Vehicle Out of Service Status

This feature allows users to configure whether a vehicle is "Out of Service" via a toggle in the Vehicle Edit/Add modal. It also adds visual indicators to the Garage and Kiosk views.

## Key Changes

- **Per-Vehicle Configuration**: A new toggle in the Vehicle Edit/Add modal allows users to specify if a vehicle is out of service.
- **Garage Visibility**: A red "Out of Service" badge appears on vehicle cards in the Garage if the status is active.
- **Kiosk Indicators**: An "Out of Service" badge appears in the vehicle summary box, and an alert banner is displayed in the expanded vehicle info view.

## Implementation Details

### Data Model (`Vehicle.cs`)

Added the `IsOutOfService` property to the `Vehicle` class.

```csharp
public bool IsOutOfService { get; set; } = false;
```

### UI Selection (`_VehicleModal.cshtml`)

Added a form switch to the vehicle modal.

```html
<div class="form-check form-switch">
    <input class="form-check-input" type="checkbox" role="switch" id="inputIsOutOfService" checked="@Model.IsOutOfService">
    <label class="form-check-label" for="inputIsOutOfService">@translator.Translate(userLanguage, "Out of Service")</label>
</div>
```

### Data Collection (`shared.js`)

The `saveVehicle` function collects the checkbox state for submission to the server.

```javascript
var vehicleIsOutOfService = $("#inputIsOutOfService").is(":checked");
// ... included in the AJAX POST to /Vehicle/SaveVehicle
```

```javascript
$.post('/Vehicle/SaveVehicle', {
    // ...
    isOutOfService: vehicleIsOutOfService,
    // ...
}
```

### API Endpoints

Dedicated endpoints were added to `APIController` to allow external tools to check and set the vehicle status.

- **Check Status**: `GET /api/vehicle/out-of-service?vehicleId={id}`
  - Returns: `{ "isOutOfService": true/false }`
- **Set Status**: `POST /api/vehicle/out-of-service?vehicleId={id}&isOutOfService={true/false}`
  - Requires: `Edit` permissions for the vehicle.
  - Returns: `OperationResponse` (Succeed/Failed).
